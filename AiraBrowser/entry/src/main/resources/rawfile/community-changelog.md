# 更新日志

## 3.1.2 (1000426)

2026-09-15

这次更新把书签同步的重计算挪到后台，并修复大屏、小说阅读和首次同步删除。

- 书签快照构建和合并改为后台 TaskPool 计算，界面不再被大书签树卡住。
- 修复口袋折叠屏展开后仍停在触控壳层的问题。
- 修复小说章节用替换字体绘制时的显示问题。
- 修复首次加入 Aira-sync 时，未匹配墓碑没有按删除处理的问题。
- 大屏搜索建议补上历史标题和来源图标，并修正全屏、对话框宽度和字体缩放。

## 3.1.1 (1000420)

2026-09-14

这次更新把光感材质铺到更多界面，加快自定义主页冷启动，并收紧底部工具栏与标签页总览。

- 管理页、设置、历史、书签、标签页总览、视频助手和小说阅读等浮层改用同一套沉浸光感材质。
- 第三方自定义主页冷启动会先显示上次画面，页面真正画出来后再交接，避免先露出空白底。
- 底部工具栏和标签页总览收成 44vp 高度，图标和按钮更对齐。
- 隐私模式默认允许运行用户脚本，可在设置里关闭。
- 修复再次打开标签页总览时卡片会抖动、大屏搜索建议发虚，以及浅色模式下网页视频按钮看不清的问题。

## 3.0.3 (1000416)

2026-09-13

这次更新大幅加快书签同步，并修复应用跳转、视频助手和深色模式配色问题。

- 书签同步的删除记录保留时间缩短，账号积累大量删除记录时同步明显更快。
- 修复首次同步可能出现的书签翻倍，以及已删除书签被重新同步回来的问题。
- 修复部分网页误判系统平台后无法唤起 App 的问题。
- 修复视频助手播放/暂停按钮状态不刷新，以及地址栏粘贴行在深色模式下的背景配色。
- 历史记录按设备归类，浏览器更新或重装后不再新增重复条目，并新增打开 Aira 历史记录的快捷键。
- 社区版不再显示无法使用的账号登录入口。

## 3.0.2 (1000410)

2026-09-11

这次更新理顺额外备份，并优化界面材质、设置首页和历史记录编辑。

- 额外备份只走 WebDAV，并从本机覆盖写入，不再当成第二个同步源去合并。
- 浏览器玻璃表面和小说阅读操作栏会模糊背后内容。
- 主页快捷方式磁贴改为不透明，低端机滑动更顺。
- 修复设置首页内容被标题栏挡住的问题。
- 历史记录编辑时，「更多」可直接打开批量复制、书签和分享菜单。

## 3.0.1 (1000408)

2026-09-10

这次更新将书签同步升级到 v4，重做底部工具栏与界面材质，并换用新的图标语言。

- 书签同步升级到 v4，同步恢复和切换更稳定。
- 底部工具栏改为系统式面板，支持拖拽排序，手势更跟手。
- 标签页、主页和设置顶栏的玻璃材质与滚动表现更稳定。
- 历史记录改为独立搜索页，自定义主页预览更容易点按。
- 应用图标换为新的线框图标集，设置与工具栏入口更易区分。
- 社区版与官方版共用同一套源码；社区版不包含官方云和华为账号。
