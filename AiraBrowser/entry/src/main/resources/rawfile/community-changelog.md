# 更新日志

## 3.2.3 (1000439)

2026-09-19

这次更新把历史记录同步的重活挪到后台、减少同步流量，修好了部分 NAS 上 WebDAV 首次同步失败的问题，并让跨设备互联在电脑端更顺手，同时统一了弹窗与命名。

- 历史记录同步的本地读取和差异计算改到后台线程，同步时界面更跟手；没有变化时直接跳过，删除少量记录也不会再重复上传整个分片。
- 兼容 fnOS 等会在加锁时生成 0 字节文件的 NAS：WebDAV 首次同步不再失败，此前留下的空快照文件也会自动修复。
- 跨设备互联适配电脑端：在电脑界面下改为设置内嵌面板，「互联教程」就地打开，不再跳成整页。
- 电脑端地址栏新增「跨设备标签页」入口，可直接查看并打开其它电脑上正在浏览的网页。
- 修复电脑端在「同步」页面点击「跨设备互联」时被切回「通用」的问题。
- 「互联教程」里的 Chrome、Edge、Firefox 换成官方图标。
- 名称统一为「跨设备互联 / 跨设备标签页 / Aira-sync 扩展 / 私有化部署 / 网页接力」。
- 弹窗按钮统一为上下排列、主操作在上；「清除浏览数据」在手机上改为沉浸式底部面板；电脑端弹窗不再因宽度限制被裁切。
- 底部工具栏手势引导按设备只提示一次，不再重复弹出。

## 3.2.2 (1000436)

2026-09-19

这次更新带来滚动沉浸效果，并修复底部工具栏的触控与冷启动主页的显示问题。

- 网页向下滚动时顶部工具栏渐隐并叠加渐进模糊，浏览更沉浸。
- 修复底部工具栏收起后，胶囊两侧空白区域吞掉点击的问题；收起时也不再紧贴底边。
- 修复已关闭的工具栏面板在页面滚动时被重新弹出的问题。
- 修复冷启动时主页封面被拉伸或跳动，以及主页快照交接时出现主题闪色的问题。
- 同步方式的名称统一为「WebDAV 同步 / 私有化部署」。

## 3.2.1 (1000433)

2026-09-17

这次更新给下载列表加上批量选择，把同步的重活挪到后台，并修复导入用户脚本、搜索引擎菜单和标签页滑动关闭的问题。

- 下载列表支持批量选择，可一次管理多个下载任务。
- 导入本地用户脚本时会覆盖已安装的同名脚本，不再留下重复条目。
- 安全 DNS 新增严格模式开关，DoH 不可用时不再回退到明文解析。
- 修复 App 代理快捷开关切换时的弹跳，以及搜索引擎菜单在键盘弹出时被顶到下方的问题。
- 标签页滑动关闭阈值改为按卡片宽度计算，更容易滑掉。
- WebDAV 同步减少重复远端读取，书签写入投影改到后台计算，超大历史记录不再因体积探测失败而中断。
- 主页快捷方式网格和历史列表的读取开销降低，重负载页面和自动同步引起的主线程卡顿减少。

## 3.1.2 (1000426)

2026-09-15

这次更新把书签同步的重计算挪到后台，并修复大屏、小说阅读和首次同步删除。

- 书签快照构建和合并改为后台 TaskPool 计算，界面不再被大书签树卡住。
- 修复口袋折叠屏展开后仍停在触控壳层的问题。
- 修复小说章节用替换字体绘制时的显示问题。
- 修复首次加入 Aira-sync 时，未匹配墓碑没有按删除处理的问题。
- 大屏搜索建议补上历史标题和来源图标，并修正全屏、对话框宽度和字体缩放。

## 3.1.1 (1000420)

2026-09-14

这次更新把光感材质铺到更多界面，加快自定义主页冷启动，并收紧底部工具栏与标签页总览。

- 管理页、设置、历史、书签、标签页总览、视频助手和小说阅读等浮层改用同一套沉浸光感材质。
- 第三方自定义主页冷启动会先显示上次画面，页面真正画出来后再交接，避免先露出空白底。
- 底部工具栏和标签页总览收成 44vp 高度，图标和按钮更对齐。
- 隐私模式默认允许运行用户脚本，可在设置里关闭。
- 修复再次打开标签页总览时卡片会抖动、大屏搜索建议发虚，以及浅色模式下网页视频按钮看不清的问题。

## 3.0.3 (1000416)

2026-09-13

这次更新大幅加快书签同步，并修复应用跳转、视频助手和深色模式配色问题。

- 书签同步的删除记录保留时间缩短，账号积累大量删除记录时同步明显更快。
- 修复首次同步可能出现的书签翻倍，以及已删除书签被重新同步回来的问题。
- 修复部分网页误判系统平台后无法唤起 App 的问题。
- 修复视频助手播放/暂停按钮状态不刷新，以及地址栏粘贴行在深色模式下的背景配色。
- 历史记录按设备归类，浏览器更新或重装后不再新增重复条目，并新增打开 Aira 历史记录的快捷键。
- 社区版不再显示无法使用的账号登录入口。

## 3.0.2 (1000410)

2026-09-11

这次更新理顺额外备份，并优化界面材质、设置首页和历史记录编辑。

- 额外备份只走 WebDAV，并从本机覆盖写入，不再当成第二个同步源去合并。
- 浏览器玻璃表面和小说阅读操作栏会模糊背后内容。
- 主页快捷方式磁贴改为不透明，低端机滑动更顺。
- 修复设置首页内容被标题栏挡住的问题。
- 历史记录编辑时，「更多」可直接打开批量复制、书签和分享菜单。
