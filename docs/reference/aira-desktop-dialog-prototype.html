Aira 桌面居中弹窗 · 视觉草稿 v2

v1 的观感偏"网页"，这版把风格基线换成 macOS 原生（AppKit 取向）。 所有尺寸按 1vp ≈ 1px 真实绘制，未缩放。数值口径见 docs/aira-desktop-dialog-design-spec.md。

①同一个弹窗，三种风格 先看差别

同一句标题、同一个动作，只换容器规范。左边是现在代码里的手机式弹窗，中间是 v1 草稿（网页感），右边是这版的 macOS 取向。

②macOS 原生 · 对话框解剖 半径 12

放进真实的窗口语境里看：macOS 弹窗浮在窗口内容之上，靠 0.5px 描边 + 多层柔和阴影 分离，而不是靠重遮罩。 模态压暗很轻（约 11%），因为原生模态靠阴影和阴影外的"失活"表达层级。
