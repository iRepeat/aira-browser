Scope

这一页有两个状态

未连接（当前这屏）：还没有任何电脑连上。顶部是配对卡，主按钮是「添加设备」——点开扫码把电脑加进来。能力区四行照常显示，书签/历史记录的开关状态如实反映。

已连接：顶部配对卡换成已连接状态（在线电脑 + 最后在线时间），「添加设备」降为次要操作；在线设备段显示在线电脑与标签页数量（未连接时这段是空态）。

四行能力里书签、历史记录可以被用户关掉（可能出现「未开启」），网页接力、跨设备标签页是常开的，只显示「已开启」，不提供关闭入口。

页面里不写的话（只在这里交代）：「点任意一行直达对应功能」「这一页不重复实现」「未连接时这段是空态」这类实现口径一律不进页面；「复制 / 查看」两种行为的差别也只在实现里体现，页面上只留一句用户能懂的话。

Open questions

需要你拍的板

  1. 1一级入口插在哪一行：设置里分组「账号与同步」，跟在「同步」后面（推荐）／排在「Aira Pro」上面／单独开一个分组。
  2. 2常开项右侧写不写状态：现在四行统一写「已开启」；也可以只让书签、历史记录显示状态，网页接力/跨设备标签页只留箭头。
  3. 3已连接态要不要也画一屏：顶部换成已连接卡 + 在线设备列表。要看我就另开一屏给你。
  4. 4在线设备列表放哪：跨设备标签页已有自己的 Sheet（标签管理页左上角），这里是做总览还是只留一个跳转。
  5. 5原 markdown 教程：保留在右上角「帮助」，还是拆进页面后彻底废弃单独成页。
  6. 6Community 发行版：没有 Aira 云、插件商店也不上架——整页隐藏，还是只留「使用自建服务器」+ 本地安装包。
  7. 7命名统一：「跨系统互联 / 跨设备使用指南 / 跨设备标签页」三个"跨"；另外这一页写「自建服务器」，同步设置里叫「私有化部署」，要对齐一个说法。
