Aira Pro

本地功能永久免费，Pro 只用于官方托管云服务。

我已阅读并同意《会员服务协议》和《自动续费服务协议》
订阅为自动续费服务，实际扣费与取消规则以华为支付页面为准。
落在 HarmonyOS 上的样子Pro 能力卡说清付费买到什么；价格卡等高对齐，选中只用描边 + 淡色底。

布局里刻意做的几个决定

  • 能力直接列成一张卡，不加表头。上面已经是「Aira Pro」标题，再写一遍「Pro 包含的能力」是重复；卡片开头就是第一项能力。
  • 顶栏只留关闭 + 恢复购买。恢复购买从底部小字提到右上角，和参考图一致，低频但能一眼找到。
  • 大标题只写「Aira Pro」。卖点交给下面的卡片，标题不抢。
  • 价格卡等高对齐。折扣角标固定在右上角，不占标题行的流式位置，两张卡的标题 / 价格 / 说明纵向完全对齐；选中不靠勾选图标，只用描边加淡底。
  • 协议勾选压缩在按钮上方。参考图没有，但 Aira 必须先勾协议才能进华为支付，占一行小字即可。
  • 横排是「支持的设备与平台」。参考图那一行是支持的模型，Aira 的等价物是云能力覆盖哪些端，不再重复列能力。

等你拍板的点

  • 这一页竖着排下来：设备横排 + 4 项能力卡 + 2 张价格卡 + 按钮，手机上一屏放不下。要不要把能力卡收成 2 行 + 「查看全部」？
  • “支持设备”横排现在是手机 / 平板 / Windows / macOS / Linux。要不要把 Chrome / Edge / Firefox 也标出来？待确认 Aira-sync 实际支持范围。
  • 两张价格卡都不写「折合」，包年卡保留右上角「−34%」角标。这个百分比怎么算（对比包月还是对比原价）需要你定，我先按当前价简单算。
